# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion focused
on the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainer via the email on their GitHub
profile. Reports are handled confidentially.
